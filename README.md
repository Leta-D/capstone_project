# KindBridge Mobile App

## Overview
The global challenge of resource wastage, particularly in urban and semi-urban areas, has led to an urgent need for efficient redistribution mechanisms. Daily, hotels, restaurants, and households generate surplus food and usable items, yet a significant proportion of these resources remain unutilized or discarded. Simultaneously, numerous communities face shortages of essential goods, creating a mismatch between resource availability and demand. Traditional donation systems, relying heavily on manual coordination and paper-based tracking, often fail to address these inefficiencies. Delays in delivery, lack of verification, and poor communication between donors and NGOs further exacerbate the problem.

##  Objectives
- Simplify the donation process for individuals and organizations  
- Provide NGOs with a centralized platform to manage donation requests  
- Enable transparent tracking of donation status  
- Encourage social responsibility and reduce waste

## User Roles

### Donor
- Post donation items with details (name, type, description, image, location)
- View donation status (Pending / Accepted / Completed)
- Manage previously posted donations

### NGO
- Browse available donation offers
- Accept donations based on organizational needs
- Track accepted and completed donations

## Application Architecture
The application follows a **modular architecture**:

- **Presentation Layer** – Flutter UI widgets and screens  
- **Business Logic Layer** – State management and validation  
- **Data Layer** – API services and data models
